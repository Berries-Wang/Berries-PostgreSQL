# 常用命令 - 登录 / 用户 / 数据库 / SQL脚本

> 以 Linux 服务器 + systemd 管理的 PostgreSQL 为例（本地编译调试环境参见 `001.启动PostgreSQL`）。
> 示例中的业务用户为 `star_router`，业务库为 `shopfi` / `shopfi_saas` / `shopfi_linorv`。

## 1. 登录 / 连接

```shell
# 本地 socket 方式登录（postgres 超级用户，免密）
sudo -u postgres psql

# TCP 方式登录指定库（最常用）
psql -h 127.0.0.1 -p 5432 -U star_router -d shopfi_linorv

# 登录时指定密码（适合脚本/临时使用，密码会进 shell history，注意安全）
PGPASSWORD='xxx' psql -h 127.0.0.1 -p 5432 -U star_router -d shopfi_saas

# 免密文件方式（推荐）：~/.pgpass，格式: host:port:db:user:password，权限必须是 0600
chmod 600 ~/.pgpass

# 直接执行一条 SQL，不进入交互界面
sudo -u postgres psql -c "SELECT version();"
psql -h 127.0.0.1 -p 5432 -U star_router -d shopfi_saas -c "SELECT now();"
```

交互界面常用元命令：

```sql
\l          -- 列出所有数据库
\c shopfi   -- 切换数据库
\dt         -- 列出当前库的表
\d t_order  -- 查看表结构（含索引、约束）
\di         -- 列出索引
\du         -- 列出用户及角色
\db         -- 列出表空间
\x          -- 切换扩展显示（宽行结果竖排，很好用）
\timing on  -- 显示每条 SQL 的执行耗时
\dn         -- 列出 schema
\df         -- 列出函数
\q          -- 退出
```

## 2. 用户管理

```shell
# 创建用户（<强口令> 替换为实际强密码）
sudo -u postgres psql -c "CREATE USER star_router WITH PASSWORD '<强口令>';"
```

```sql
-- 修改密码
ALTER USER star_router WITH PASSWORD '<新口令>';

-- 把某用户设为只读
ALTER USER star_router SET default_transaction_read_only = on;

-- 删除用户（需先删除其拥有的对象或转移 OWNER）
DROP USER star_router;

-- 查看用户列表
\du
SELECT usename FROM pg_user;
```

## 3. 数据库管理

```shell
# 创建数据库并指定 owner 为 star_router
sudo -u postgres createdb -O star_router shopfi
sudo -u postgres createdb -O star_router shopfi_saas

# createdb 等价于 SQL：
# sudo -u postgres psql -c "CREATE DATABASE shopfi OWNER star_router;"

# 指定编码/locale 创建（避免 COPY 排序报错等问题）
sudo -u postgres createdb -O star_router -E UTF8 --lc-collate=C --lc-ctype=C shopfi

# 删除数据库（不允许有活动连接）
sudo -u postgres dropdb shopfi_linorv

# 强制踢掉连接后再删
sudo -u postgres psql -c "SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE datname='shopfi_linorv' AND pid<>pg_backend_pid();"
sudo -u postgres dropdb shopfi_linorv
```

权限授予（新建库后常用）：

```sql
-- 库级：允许连接 + public schema 下的建表/使用权限（PG15+ public schema 默认不再对所有人开放 CREATE）
GRANT CONNECT ON DATABASE shopfi TO star_router;
GRANT USAGE, CREATE ON SCHEMA public TO star_router;

-- 表级：把已有表的权限授给用户
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO star_router;
-- 序列
GRANT USAGE, SELECT ON ALL SEQUENCES IN SCHEMA public TO star_router;
-- 以后新建的表自动授权（可选）
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON TABLES TO star_router;
```

## 4. 访问控制（pg_hba.conf）

新建用户后若用 TCP 连不上（`no pg_hba.conf entry` 报错），需要在 `pg_hba.conf` 加一行：

```shell
# 找到配置文件位置
sudo -u postgres psql -c "SHOW hba_file;"

# 在 pg_hba.conf 中按格式追加（数据库 用户 来源地址 认证方式）：
#   host  shopfi  star_router  127.0.0.1/32  scram-sha-256
# 一个用户访问多个库，可以把库名写成一个逗号列表，或用 all

# 改完 reload 生效（不必重启）
sudo systemctl reload postgresql
```

> 注意：scram-sha-256 要求 `postgresql.conf` 中 `password_encryption = scram-sha-256`（PG14+ 默认即是）。
> 修改认证方式后老密码可能是 md5 存的，需要 `ALTER USER ... WITH PASSWORD` 重设一次。

## 5. 导入 / 导出 SQL 脚本

```shell
# 导入 SQL 脚本（迁移脚本强烈加 -v ON_ERROR_STOP=1，出错立即终止，避免半成品数据）
psql -h 127.0.0.1 -p 5432 -U star_router -d shopfi_saas -v ON_ERROR_STOP=1 -f 20260924_pg_migrate_data.sql

# 已在 psql 交互界面内，用 \i 导入
shopfi_saas=# \i 20260924_pg_migrate_data.sql

# 导出建库脚本（schema + 数据，自定义格式支持并行恢复/选择性恢复）
pg_dump -h 127.0.0.1 -U star_router -Fc -f shopfi_saas.dump shopfi_saas

# 只导 schema 不导数据
pg_dump -h 127.0.0.1 -U star_router -s -f shopfi_saas_schema.sql shopfi_saas

# 只导数据
pg_dump -h 127.0.0.1 -U star_router -a -f shopfi_saas_data.sql shopfi_saas

# 恢复自定义格式 dump
pg_restore -h 127.0.0.1 -U star_router -d shopfi_saas -v shopfi_saas.dump

# 导出纯 SQL 格式（跨版本兼容性更好）
pg_dump -h 127.0.0.1 -U star_router -Fp -f shopfi_saas.sql shopfi_saas

# 全库集群备份（所有库+用户/角色定义）
sudo -u postgres pg_dumpall > all_$(date +%Y%m%d).sql
```

导出/导入 CSV（psql 客户端侧，\copy 不要求服务器端文件权限）：

```sql
-- 导出查询结果到本地 CSV
\copy (SELECT * FROM t_order WHERE created_at > '2026-09-01') TO '/tmp/orders.csv' WITH CSV HEADER;

-- 从本地 CSV 导入表
\copy t_order FROM '/tmp/orders.csv' WITH CSV HEADER;
```

## 6. 服务管理（systemd）

```shell
sudo systemctl start postgresql      # 启动
sudo systemctl stop postgresql       # 停止
sudo systemctl restart postgresql    # 重启（改 port/max_connections 等需 restart）
sudo systemctl reload postgresql     # 重载配置（改 pg_hba.conf、多数 postgresql.conf 参数够用）
sudo systemctl status postgresql     # 状态
sudo systemctl enable postgresql     # 开机自启

# 查看数据目录/端口/配置文件位置
sudo -u postgres psql -c "SHOW data_directory;"
sudo -u postgres psql -c "SHOW config_file;"
sudo -u postgres psql -c "SHOW port;"
```

## 7. 会话管理

```sql
-- 查看当前所有连接：谁连的、连的哪个库、在执行什么
SELECT pid, usename, datname, client_addr, state, wait_event_type, query_start, query
FROM pg_stat_activity
WHERE state <> 'idle';

-- 连接数 / 上限
SELECT count(*), (SELECT setting FROM pg_settings WHERE name='max_connections') AS max_conn
FROM pg_stat_activity;

-- 取消一条正在执行的 SQL（不断开连接）
SELECT pg_cancel_backend(<pid>);

-- 强制断开一个连接
SELECT pg_terminate_backend(<pid>);

-- 断开某个库的所有连接（删库/恢复前常用）
SELECT pg_terminate_backend(pid)
FROM pg_stat_activity
WHERE datname = 'shopfi_linorv' AND pid <> pg_backend_pid();
```

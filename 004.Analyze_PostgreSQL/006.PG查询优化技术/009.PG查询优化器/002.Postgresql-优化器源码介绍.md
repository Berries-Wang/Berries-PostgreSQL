# PG 查询优化器源码介绍（PostgreSQL 18.6，src/backend/optimizer/）

```text
 src/backend/optimizer/
 ├── plan/   规划主流程: 预处理调度、路径搜索调度、Path→Plan 转换、子查询
 ├── path/   路径生成: 扫描路径、连接顺序搜索、物理连接方式、代价模型、等价类
 ├── prep/   预处理实现: jointree 上拉改写、targetlist、聚合、集合操作
 ├── util/   公共设施: RelOptInfo/Path 节点构造、条件处理、继承展开、统计封装
 └── geqo/   遗传算法连接顺序搜索 (GEQO = GEnetic Query Optimization)
```

## geqo/ —— 遗传算法（表多时的连接搜索替代）

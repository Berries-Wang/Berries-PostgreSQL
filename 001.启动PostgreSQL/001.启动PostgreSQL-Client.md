# 启动PostgreSQL-Client

> 本篇记录本地源码编译环境下客户端工具的初始化与首次连接过程。
> 客户端工具都在编译输出的 BIN_DIR 下：`initdb` / `pg_ctl` / `createdb` / `createuser` / `dropdb` / `dropuser` / `psql` ...
> Server 的启动方式见 [000.启动PostgreSQL-Server.md](000.启动PostgreSQL-Server.md)；登录/用户/数据库/SQL脚本等常用命令的完整整理，见该文档的「常用命令 - 登录 / 用户 / 数据库 / SQL脚本」一节。

initdb 输出中有两个关键信息：

- `The files belonging to this database system will be owned by user "wei".` —— 操作系统用户 `wei` 就是本集群的数据库超级用户，后续所有命令都不需要 `sudo -u postgres`；
- 结尾直接给出了启动命令 `pg_ctl -D <DATADIR> -l logfile start`（启动细节见 [000.启动PostgreSQL-Server.md](000.启动PostgreSQL-Server.md)）。

## 2. 创建数据库并连接

```shell
     # 创建数据库 : 注意，参数 wei 是计算机的用户名, 参考 initdb 输出: 'The files belonging to this database system will be owned by user "wei".'
     # （initdb 只自带 postgres/template0/template1 三个库；不带参数的 psql 会连"与当前系统用户同名的库"，所以要先创建它）
     wei@Wang:~/WorkSpace/open_source/PostgreSQL/000.SOURCE_CODE/PostgreSQL-16.2/000.build-output/002.BIN_DIR$ ./createdb wei
     
     # 创建业务数据库示例
     wei@Berries:~/OPEN_SOURCE/Berries-PostgreSQL/000.SOURCE_CODE/PostgreSQL-16.2/000.build-output$ ./002.BIN_DIR/createdb shopify_payment_demo
     
     # 使用命令行工具连接（不带参数：本地 socket + 当前系统用户名 + 同名数据库）
     wei@Wang:~/WorkSpace/open_source/PostgreSQL/000.SOURCE_CODE/PostgreSQL-16.2/000.build-output/002.BIN_DIR$ ./psql 
     psql (16.2)
     Type "help" for help.
     
     wei=# 
```

psql 连接参数也可以显式指定，与上面等价：

```shell
./psql -h 127.0.0.1 -p 5432 -U wei -d wei
```

## 3. 创建用户 / 创建数据库（速查）

```shell
./createuser -P app_user                     # 创建用户，-P 交互式设置密码
./createdb -O app_user app_db                # 创建数据库并指定属主（owner）
./psql -h 127.0.0.1 -p 5432 -U app_user -d app_db   # 以新用户连接验证
./dropdb app_db && ./dropuser app_user       # 删除数据库 / 删除用户
```

等价 SQL、授权（GRANT）、pg_hba.conf、导入导出等完整命令，见 [000.启动PostgreSQL-Server.md](000.启动PostgreSQL-Server.md) 的「常用命令」一节。
